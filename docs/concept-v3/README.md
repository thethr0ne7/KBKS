# KBKS Auto — Visual Direction v3

## Формула

- Hero: маршрутная визуализация с линейным автомобилем, городским/горным контекстом и анимированной линией.
- Структура: спокойный официальный лендинг — программы, маршрут, центр доверия, FAQ, консультация.
- Контент: только сведения текущего прототипа; цена, сроки, даты набора, автопарк, преподаватели и отзывы не выдумываются.
- Mobile: отдельный экран `mobile.html`, а не механическое уменьшение desktop.

## Просмотр

- Desktop: `/concept-v3/`
- Mobile: `/concept-v3/mobile.html`

## Ограничения

- Форма демонстрационная и не передаёт данные.
- Категории C и CE показаны только как неподтверждённые карточки.
- Реальный автопарк не изображается.
