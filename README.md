# KBKS AUTO DESIGN SYSTEM — HTML prototype

Интерактивный статический прототип будущего раздела:

```text
https://kb-ks.ru/avtoshkola/
```

Прототип нужен для проверки визуального направления, пользовательского маршрута, состояний компонентов, мобильной версии и последующего переноса в отдельный WordPress-шаблон `page-avtoshkola.php`.

## Что уже реализовано

- визуальная автономия внутри корневого контейнера `.kbks-auto`;
- переходная связь с основным сайтом КБКС;
- адаптивный Hero с метафорой «Маршрут к правам»;
- интерактивные программные вкладки;
- честные статусы подтверждения данных;
- интерактивный маршрут обращения;
- Trust Center для документов;
- FAQ на нативном `<details>`;
- демонстрационная форма с состояниями error, loading и success;
- библиотека кнопок, полей, иконок, цветов и типографики;
- reduced motion;
- мобильная навигация;
- примеры Print, Outdoor, QR и Social Media;
- клавиатурное управление вкладками;
- focus-visible и семантическая разметка.

## Структура

```text
docs/
├── index.html   — структура и контент прототипа
├── styles.css   — локальная дизайн-система
└── app.js       — минимальные интерактивные механики
```

## Как открыть локально

Можно просто скачать репозиторий и открыть:

```text
docs/index.html
```

Для корректного тестирования через локальный сервер:

```bash
python -m http.server 8080 --directory docs
```

После этого открыть:

```text
http://localhost:8080
```

## Как включить GitHub Pages

После слияния ветки в `main`:

1. Открыть **Settings** репозитория.
2. Перейти в **Pages**.
3. В разделе **Build and deployment** выбрать `Deploy from a branch`.
4. Выбрать ветку `main`.
5. Выбрать папку `/docs`.
6. Нажать **Save**.

Ожидаемый адрес:

```text
https://thethr0ne7.github.io/KBKS/
```

До включения Pages этот адрес может не работать.

## Важное ограничение по данным

Это не публичная оферта и не готовая страница КБКС.

В прототипе намеренно не указаны как факты:

- цены;
- сроки;
- даты наборов;
- список автомобилей;
- преподаватели;
- отзывы;
- процент сдачи;
- рассрочка;
- личный кабинет;
- онлайн-оплата.

Категории `C` и `CE` показываются только как демонстрация механики и имеют статус «требует подтверждения».

Сгенерированный силуэт автомобиля является декоративной схемой и должен быть заменён реальной фотографией после съёмки.

## Перенос в WordPress

После получения доступа к сайту прототип переводится в следующую структуру:

```text
wp-content/themes/kbks-child/
├── page-avtoshkola.php
├── functions.php
├── template-parts/avtoshkola/
└── assets/avtoshkola/
    ├── kbks-auto.css
    ├── kbks-auto.js
    └── images/
```

Основные правила переноса:

- сохранить `.kbks-auto` как корневой namespace;
- не добавлять глобальные стили для `body`, `h1`, `button`, `input` и `.container`;
- подключать CSS и JS только на странице `/avtoshkola/`;
- оставить общий header/footer КБКС либо создать согласованную переходную оболочку;
- заменить демонстрационные данные подтверждёнными WordPress-полями;
- подключить утверждённый form plugin;
- загрузить реальные документы и фотографии через медиатеку WordPress.
